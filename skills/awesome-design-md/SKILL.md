# awesome-design-md

Reference markdown for real-world brand & product design systems. Sourced from <https://github.com/VoltAgent/awesome-design-md> (MIT — see `LICENSE`). Each file in `design-md/<brand>/` captures one brand's system: typography stack, color palette, motion values, spacing scale, iconography rules, voice notes.

## How to use

1. When a user names a brand for reference ("make it feel like Linear", "Apple-style hero", "Framer-y motion"), grep `design-md/` for that brand and read the file.
2. Extract the specific dimensions relevant to the task — palette for a landing page, motion curves for animation, spacing scale for a layout — and adapt to the host project's tokens.
3. Prefer many small cues from a reference over wholesale copying: type stack + one motion curve + palette hue is usually enough to evoke the target without imitating it.

These docs describe publicly observable design choices. Do not reproduce logotypes, wordmarks, or trademarked visual assets. Use for education, inspiration, and directional token work — not to build a clone that could be mistaken for the original brand.
